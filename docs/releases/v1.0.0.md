# PoMade v1.0.0

Code pushed. First impression handled.

PoMade's first stable release combines three README styles, repository inspection, reviewed plans, optional local hooks, and GitHub push maintenance.

## New since the release candidate

- **Codex plugin installation:** portable manifest, repository marketplace, mascot icon, and plugin-picker metadata. Installed and recognized with Codex's native plugin manager.
- **Claude Code packaging:** native manifest validation, portable skill, and marketplace install instructions.
- **Bundled agent hooks:** session-start and pre-tool context before shell git pushes. Hooks add guidance without modifying files or granting permissions.
- **Optional Git pre-push checks:** `pomade hooks install`, `status`, `check`, and `uninstall`. Checks catch stale generated presentation and uncommitted README/cover edits. Existing hooks and custom hook managers are preserved.
- **Complete product website:** functions, installation, hook setup, templates, live README Studio, command/config reference, troubleshooting, workflow, and changelog. The design follows a rendered README with normal website navigation.
- **Node.js 22+ baseline** for the CLI and hooks.

## Included from rc.1

Simple, Signature, and Motion use the same renderer in the CLI and Studio. The CLI reads real repository facts, saves reviewable plans, rejects stale files and malformed markers, and maintains generated sections without changing surrounding owner text. The GitHub Action refreshes README/covers after pushes and optionally synchronizes About, homepage, and topics with a scoped token.

## Install

```sh
npm install -g https://github.com/Gurtejhundal/Pomade/releases/download/v1.0.0/pomade-1.0.0.tgz
pomade --version
```

Codex:

```sh
codex plugin marketplace add Gurtejhundal/Pomade --ref v1.0.0
codex plugin add pomade@pomade
```

Claude Code:

```text
/plugin install pomade --marketplace Gurtejhundal/Pomade
```

Restart or open a new chat after installing. Review/trust lifecycle hooks in the host. The CLI and Git hook are separate installations; the plugin does not silently install either.

Inside your project:

```sh
pomade init --preset signature --approved
pomade diff
pomade apply --approved
pomade hooks install --approved
```

Review the initial diff before applying. Commit the generated config, README, media, and workflow. The optional Git hook must be installed in each clone. See [the installation guide](https://pomade-swart.vercel.app/install).

## Assets

- `pomade-1.0.0.tgz`: compiled CLI plus bundled skill/plugin resources. Install with npm as above.
- `pomade-plugin-v1.0.0.zip`: plugin manifests, marketplace catalogs, skills, hooks, and icon. The CLI is installed separately.
- Source archives: full project, website, tests, and documentation.

This release does not publish the package to the npm registry or claim acceptance into a public plugin directory.

## Verification and limits

The release pipeline runs TypeScript checks, the test suite, Claude Code's strict native plugin validator, package installation, and CLI smoke checks before publishing assets. CI also exercises Linux, macOS, and Windows on Node 22/24/26. The website is checked on desktop and mobile.

Repository inspection is heuristic. Authored claims still need review, and capture planning does not record your app automatically. Local hooks can be bypassed by Git and do not replace branch protection or CI. Full interactive model sessions in every agent host were not tested. The development-only picomatch advisory remains tracked; runtime dependency audits reported zero findings.
