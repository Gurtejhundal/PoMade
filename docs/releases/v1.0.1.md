# PoMade v1.0.1

Repository polish on every push.

This patch packages the updated product pitch and About-writing guidance into the CLI and plugin downloads.

## Changes

- **Plugin picker:** “Repository polish on every push.”
- **About pitch:** “Your agent writes the code. PoMade handles the README, media, About, and topics. Every push looks finished.”
- **Skill behavior:** every presentation pass includes a concise, factual GitHub About pitch. Reuse an accurate existing pitch, avoid unsupported claims, and store reviewed copy in `.pomade.json` for authorized metadata synchronization.
- Updated version labels, installation examples, README samples, and release links.

## Install or update

```sh
npm install -g https://github.com/Gurtejhundal/Pomade/releases/download/v1.0.1/pomade-1.0.1.tgz
```

Codex:

```sh
codex plugin marketplace add Gurtejhundal/Pomade --ref v1.0.1
codex plugin add pomade@pomade
```

Open a new chat or restart the app to load the refreshed plugin. Review/trust bundled hooks in the host. Existing local Git hooks are unchanged.

## Downloads

- `pomade-1.0.1.tgz`: installable CLI with plugin resources.
- `pomade-plugin-v1.0.1.zip`: manifests, marketplaces, skills, hooks, and icon.
- Source archives: full project and website.

v1.0.0 remains available as historical release content. This is a stable patch release, not an npm registry publication. The development-only dependency advisory remains tracked; full interactive event delivery in every agent host is not asserted.
