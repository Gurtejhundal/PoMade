# PoMade v1.0.0-rc.1

The first PoMade release candidate brings repository presentation into the coding-agent and git-push workflow.

## What's included

- Three README styles: **Simple**, **Signature**, and **Motion**, shared by the CLI and browser Studio.
- `init` and `sync` commands plus a GitHub Action for maintaining managed README sections and cover assets after pushes.
- Optional GitHub About, homepage, and topic updates using a scoped repository token.
- A portable agent skill and Claude Code plugin manifest.
- Real sample media, animated SVG covers, and static alternatives.
- Saved-plan application, stale-file checks, malformed-marker protection, and filesystem boundary checks.

## Install the CLI

Download `pomade-1.0.0-rc.1.tgz` from this release, then run with Node.js 22 or newer:

```sh
npm install -g ./pomade-1.0.0-rc.1.tgz
pomade --help
```

Inside your project:

```sh
pomade init --preset signature --approved
pomade diff
pomade apply --approved
```

Review the first diff before adopting generated sections. Commit the generated config, workflow, README, and media with your project. Configure `POMADE_TOKEN` only if you want About/topics synchronization.

The tarball is a packaged CLI release; it is not an npm registry publication. Use the included source archive for the full website, examples, and local plugin directory.

## Verification and known limits

- 105 tests passed; CI passed on Node 22, 24, and 26 across Linux, macOS, and Windows.
- Website production build, deployed routes, Studio export, and push-triggered README/metadata maintenance were verified.
- Native Claude Code plugin loading and Node 18 execution were not tested.
- This is a pre-release. Repository inspection is heuristic, and owner-written claims still need review.
- The development test toolchain has an upstream picomatch advisory without a published patch at release preparation. Production dependency audits reported zero findings.

See [the audit](https://github.com/Gurtejhundal/Pomade/blob/main/docs/audit/2026-11-18.md) and [push workflow setup](https://github.com/Gurtejhundal/Pomade/blob/main/docs/PUSH_WORKFLOW.md).
