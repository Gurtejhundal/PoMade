# Naming and visual identity

## Recommendation

**RepoAtelier** is the working product name: memorable, clear enough to explain, and evokes a workshop that refines a raw repository. Tagline: **Make every repo worth opening.** Secondary: **From first commit to a README worth reading.**

### Alternative candidates (not availability-cleared)

1. **RepoHalo** — short and polished; risk: generic branding and possible collisions.
2. **GitDapper** — playful developer voice, slightly less serious for enterprise.
3. **RepoAtelier** — distinctive craft angle, longer to type.

**Avoid Gitlike as the primary name.** `gitlike.dev` already advertises a decentralized version-control system; collision and confusion risks are real. `RepoPolish`, `RepoLoom`, and `GitGleam` also have existing products/projects; search before choosing any name, GitHub handle, domain, npm scope and trademark.

## Logo concept (future, not included in this ZIP)

One stylized repository window paired with a subtle fold/crease or a meticulous stitch—the idea is curation, not magic. Monochrome core mark; optional single restrained accent color. A clean 16–24px icon must work without gradients, text or tiny stars. Avoid copying GitHub's Octocat or another agent's mascot.

## Brand voice

Competent, concise and a little playful. Human technical writing, not fake enthusiasm. Example: 'Your README shouldn't describe a different version of your app.'

## Repository About copy (proposed)

> An agent-native toolkit that keeps GitHub READMEs, demos, metadata, and releases accurate, polished, and in sync with the code.

## Discoverability topics (only when implemented)

`agent-skills`, `developer-tools`, `github`, `readme`, `documentation`, `cli`, `automation`, `open-source`. Use GitHub topics that match shipped capabilities; don't claim `mcp-server` before one exists.

## Social card specification

Design 1280×640 PNG with solid background, mark, name, and short specific promise. GitHub documents minimum 640×320 and recommends 1280×640 for social previews, with file under 1 MB. Upload via repository Settings social preview as documented. Validate against GitHub light/dark use.
